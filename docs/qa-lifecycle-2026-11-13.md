# 房間與線上人員生命週期驗證

日期：2026-11-13。環境：Windows、Node.js 22.23.2、Chromium（Playwright）。

- 根因：回大廳／換房只解除 socket 綁定，舊席位仍標成連線；觀眾阻止關房；同身分多分頁共用斷線旗標。
- 統一離房入口，最後一條房內連線離開才移除成員。線上人數依連線身分去重。
- 斷線席位沿用 60 秒寬限；期限到點釋放。只剩觀眾時關房、撤銷邀請並移除大廳列表。
- 自動重連先完成身分交握，再恢復原房間或大廳訂閱；房間不存在則回大廳。
- 主動離線移除 socket 事件監聽，避免舊連線狀態影響新畫面。

驗證：

- `npm test`：通過，含 7 項新增生命週期情境及 91 項規則測試。
- `npm run test:online`：43 項通過，包含完整一局、再開一局、邀請與觀戰。
- `node scripts/lifecycle-browser.cjs`：4 項通過，包含大廳／房內重連、關房與停止連線。
- `npm run test:browser`：249 項通過，含手機直橫、平板直橫、桌機、設定與單機流程。
- 實際截圖位於 `screenshots/`（忽略產物）；已檢視平板橫向對局畫面。
- 無設定 formatter；依既有風格手動整理，`git diff --check` 通過。檔案採 UTF-8 無 BOM。

最後依 loop-engineering 檢視、修復、驗證一輪，關房與重連條件均有自動化斷言。未修改玩法或部署設定，未驗證正式服務的自動部署結果。本機 Node 版本低於專案宣告的 26.12.1；未宣稱已驗證該版本。原有 QA 文件刪除不納入本次提交。
